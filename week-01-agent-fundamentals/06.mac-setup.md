# 06. Mac Setup

---

This lecture walks Mac and Linux users through the five-step environment setup process.

**Step 1 — Clone the Repository:** Open Terminal from Applications > Utilities. Create a projects folder with `mkdir projects` and navigate into it with `cd projects`. Verify Git is installed using `git --version`; if not, run `xcode-select --install`. Visit `github.com/ed-donner/agents`, click the green Code button, copy the HTTPS URL, and run `git clone [url]` in Terminal. Navigate into the new `agents` folder with `cd agents`. This is your project root.

**Step 2 — Install Cursor:** Go to `cursor.com`, sign up (Google credentials work), and download the Mac installer. Drag Cursor into Applications and launch it. Click **Open Project**, navigate to the `agents` folder, and click Open. Close any welcome tabs or chat panels. Two extensions are required: install **Python** from AnySphere and **Jupyter** from Microsoft via View > Extensions.

**Step 3 — Install UV:** Copy the installation command from the UV installation page linked in the setup instructions. In Cursor, open Terminal via View > Terminal or `Ctrl + `` `, paste the command, and run it. Quit and relaunch Cursor. Verify with `uv --version`, then run `uv sync` from the project root. This installs Python 3.12, all dependencies, and creates a `.venv` virtual environment. Going forward, use `uv run` instead of `python` to execute scripts.

**Step 4 — Set Up OpenAI Key:** Go to `platform.openai.com`, log in or sign up. Under Settings > Billing, add a minimum of $5 credit (total course cost will be a few dollars). Under API Keys, create a new secret key with default project and permissions. Copy the key immediately. Do not paste it into Notepad or any formatting text editor — this can corrupt the key. Paste directly into Cursor in the next step. Alternatives to OpenAI (Gemini, DeepSeek, etc.) are documented in the README.

**Step 5 — Create the .env File:** In Cursor's Explorer panel, right-click and select New File. Name it exactly `.env`. Inside, type `OPENAI_API_KEY=` followed by your key — no spaces, no quotes. The variable name must be spelled exactly `OPENAI_API_KEY`. Save the file. Setup is complete.
