# 06. Mac Setup

This lecture walks Mac and Linux users through the five-step environment setup process.

## Step 1 — Clone the Repository

- Open Terminal from **Applications > Utilities**
- Create a projects folder and navigate into it: `mkdir projects` then `cd projects`
- Verify Git is installed: `git --version`
- If no version appears, install developer tools: `xcode-select --install`
- Visit `github.com/ed-donner/agents` in a browser
- Click the green **Code** button, select **HTTPS**, and copy the URL
- In Terminal, clone the repository: `git clone [pasted-url]`
- Navigate into the new folder: `cd agents`
- This location is your **project root**

## Step 2 — Install Cursor

- Go to `cursor.com`, sign up (Google credentials work) or log in
- Download the Mac installer and drag Cursor into the **Applications** folder
- Launch Cursor, click **Open Project**, navigate to the `agents` folder, and click **Open**
- Close any welcome tabs or chat panels
- Install two extensions via **View > Extensions**: **Python** (from AnySphere) and **Jupyter** (from Microsoft)

## Step 3 — Install UV

- Open the UV installation page linked in the setup instructions and copy the installation command
- In Cursor, open Terminal via **View > Terminal** or `Ctrl + `` `, paste the command, and run it
- Quit Cursor completely, then relaunch to refresh environment variables
- Verify installation: `uv --version`
- From the project root, run: `uv sync`
- This installs Python 3.12, all dependencies, and creates a `.venv` virtual environment (takes 3–4 minutes)
- Going forward, use `uv run` instead of `python` to execute scripts

## Step 4 — Set Up OpenAI Key

- Go to `platform.openai.com` and log in or sign up
- Under **Settings > Billing**, add a minimum of $5 credit (total course cost will be a few dollars)
- Under **API Keys**, click **Create new secret key**, give it a name, select **Default project**, leave permissions as default, and click **Create secret key**
- Copy the key to your clipboard immediately
- **Warning:** Do not paste the key into Notepad or any formatting text editor — auto-formatting can corrupt the key. Paste directly into Cursor in Step 5.
- Note: Alternatives to OpenAI (Gemini, DeepSeek, etc.) are documented in the README

## Step 5 — Create the .env File

- In Cursor's Explorer panel, right-click and select **New File**
- Name the file exactly `.env`
- Inside the file, type: `OPENAI_API_KEY=your-key-here`
- Rules: no spaces before or after the equals sign, no quote marks, variable name must be spelled exactly `OPENAI_API_KEY`
- Paste your key directly after the equals sign (key should begin with `sk-proj-`)
- Save the file with `Cmd+S`

Setup is complete.
