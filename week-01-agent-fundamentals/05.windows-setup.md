# 05. Windows Setup

---

## 1. Introduction

This lecture covers environment setup for Windows users. Mac users should proceed to the next lecture. Linux users may follow the Mac instructions.

---

## 2. Windows Gotchas

Four common issues to address before starting:

| Gotcha | Issue | Solution |
| :--- | :--- | :--- |
| 1 | Script execution permissions | Google the error message; follow steps to grant authority |
| 2 | Antivirus/VPN interference | Temporarily disable if you get unexplained errors |
| 3 | 260-character path limit | Disable this Windows setting per instructions |
| 4 | Microsoft Build Tools | Required before Crew AI Week; install if new to programming |

---

## 3. Five-Step Setup Process

### Step 1: Install Cursor IDE

Download from `cursor.com`. The free Hobby plan is sufficient. Sign in to enable AI autocomplete features. Cursor is a fork of VS Code — use VS Code if preferred.

### Step 2: Clone the Repository

- Verify Git is installed: `git --version`
- Navigate to your projects folder: `cd ~/projects`
- Clone the repo: `git clone [repository-url]`
- Enter the directory: `cd agents`

### Step 3: Open Project and Install Extensions

- Open the `agents` folder in Cursor
- Verify the title bar shows "AGENTS"
- Install two extensions: **Python** (from AnySphere) and **Jupyter** (from Microsoft)

### Step 4: Install UV and Sync

- Install UV using the command from the setup instructions
- Verify: `uv --version`
- Run: `uv sync`
- This installs Python (if needed), all dependencies, and creates a `.venv` folder
- If errors occur, consult Question 11 in the FAQ

### Step 5: API Keys and .env File

Covered in the next lecture alongside Mac users.

---

## 4. Completion

After `uv sync` completes successfully, the Windows-specific setup is done. Skip the Mac lecture and proceed to the API keys and environment file setup.
