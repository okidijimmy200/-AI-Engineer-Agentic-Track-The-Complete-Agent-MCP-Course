# Lecture Note: 15. Ollama Local LLMs (with Code Integration)

## Introduction to Local LLM Deployment with Ollama

This lecture delves into the practical aspects of running Large Language Models (LLMs) locally on your machine using **Ollama**. While cloud-based LLMs offer convenience and scalability, local deployment provides enhanced privacy, reduced latency, and cost-effectiveness for development and experimentation. This note integrates the lecture transcript with practical code examples from the lab notebook to guide you through setting up and interacting with local LLMs.

## I. Ollama Installation and Model Selection

Ollama simplifies the process of running open-source LLMs locally. However, careful consideration of hardware resources and model size is crucial for a smooth experience.

### A. Installation

1. **Download Ollama**: Visit [ollama.com](https://ollama.com) and download the appropriate installer for your operating system (Mac, Linux, or Windows).

1. **Installation Process**: Follow the on-screen instructions. After installation, Ollama will run a local web service, typically on `http://localhost:11434`.

1. **Troubleshooting**: If Ollama commands are not recognized, you may need to restart your terminal, IDE (e.g., Cursor ), or even your computer to refresh environment paths.

### B. Model Selection Considerations

When choosing models from the [Ollama models page](https://ollama.com/library), pay close attention to their size:

- **Resource Intensity**: Models with many parameters (e.g., 70 billion parameters) require significant RAM and GPU resources. For most personal computers, models around **3 gigabytes or less** are recommended.

- **Avoid ****`cloud`**** models**: Models ending with `:cloud` are designed for cloud inference services (similar to Groq) and do not run locally on your machine.

- **Recommended Starter Models**: `llama3.2` (smaller variations) and `Gemma 4` (smaller variations) are good starting points.

## II. Interacting with Ollama via Command Line and Python

Ollama provides both command-line interface (CLI) tools and an OpenAI-compatible API endpoint for interaction.

### A. Essential Ollama CLI Commands

These commands are executed in your terminal:

- `ollama serve`: Starts the Ollama local server. (You might get an error if it's already running).

- `ollama pull <model_name>`: Downloads a specified model (e.g., `ollama pull llama3.2`).

- `ollama ls`: Lists all models currently downloaded on your machine.

- `ollama rm <model_name>`: Removes a downloaded model.

**Example 2.1: Pulling a Model (from notebook)**

```python
# This command is executed in the terminal or a Jupyter cell with '!' prefix
!ollama pull llama3.2
```

### B. Verifying Ollama Service Status

You can check if the Ollama service is running and list available models programmatically.

**Example 2.2: Checking Ollama Service Status**

```python
import requests

# Check if Ollama is running
response = requests.get("http://localhost:11434" )
print(response.content.decode())
# Expected output: "Ollama is running"
```

**Example 2.3: Listing Downloaded Models**

```python
# List all models downloaded via Ollama
models = requests.get("http://localhost:11434/v1/models" ).json()
for model in models.get("data"):
    print(model.get("id"))
```

## III. Making API Calls to Local Ollama Models

Ollama exposes an OpenAI-compatible API endpoint, allowing you to use the familiar `OpenAI` Python client library to interact with local models.

### A. Initializing the Ollama Client

```python
from openai import OpenAI

OLLAMA_BASE_URL = "http://localhost:11434/v1"
ollama = OpenAI(base_url=OLLAMA_BASE_URL, api_key="ollama" ) # 'ollama' is a dummy key for local setup
```
