# 07. API Keys and Environment Variables

## 1. Introduction

Modern AI applications typically communicate with large language models through APIs. Before an application can access these models, developers must configure authentication credentials and securely manage sensitive configuration values.

This lecture introduces:

- OpenAI API authentication
- API key management
- Environment variables
- Secure application configuration

The goal is to create a development environment where applications can safely communicate with AI services without exposing sensitive credentials.

---

# Section 1 — OpenAI API Authentication and Environment Configuration

## 2. OpenAI API vs ChatGPT

OpenAI provides two separate products:

### ChatGPT

ChatGPT is a user-facing application that allows humans to interact with AI models through a graphical interface.

Examples:

- Asking questions
- Generating content
- Interactive problem solving

ChatGPT is designed for direct human interaction.

---

### OpenAI API

The OpenAI API is a developer interface that allows software applications to programmatically access AI models.

Applications use the API to build:

- AI agents
- Chatbots
- Document processing systems
- Automated workflows
- AI-powered products

The API requires separate authentication using API keys.

A ChatGPT account and an API account are separate systems.

---

# 3. Creating an OpenAI API Account

To use the OpenAI API:

1. Create an account on the OpenAI developer platform.
2. Create an organization.
3. Configure billing.
4. Generate an API key.

The organization acts as a container for API usage, billing, and access management.

Recommended organization setup:

| Field | Value |
|---|---|
| Organization name | Personal name + Education/Research |
| User type | Student |

---

# 4. API Billing

The OpenAI API operates using usage-based billing.

Unlike ChatGPT subscriptions, API usage is charged based on:

- Model usage
- Input tokens
- Output tokens

A small initial credit balance is sufficient for learning and experimentation.

For development purposes, a minimum credit amount can be added through:

```
Settings → Billing
```

Alternative AI providers with free tiers can also be used.

---

# 5. API Keys

## 5.1 Purpose of API Keys

An API key is a secret authentication credential used by applications to prove their identity when communicating with OpenAI services.

Example:

```text
Application
     |
     |
 API Key
     |
     |
 OpenAI API
```

Without a valid API key, applications cannot access protected API endpoints.

---

## 5.2 Creating an API Key

API keys are created from:

```
Settings → API Keys
```

During creation:

- Provide a descriptive name.
- Use the default project.
- Keep permissions enabled for development.

After creation, the key should be copied immediately because secret keys are only displayed once.

---

# 6. API Key Security

API keys should be treated as sensitive credentials.

They should never be:

- Shared publicly
- Uploaded to GitHub
- Embedded directly inside application code
- Stored in screenshots or documentation

Example of insecure code:

```python
OPENAI_KEY = "sk-proj-example-key"
```

This creates a security risk because anyone with access to the code can use the credential.

The recommended approach is storing keys as environment variables.

---

# 7. Environment Variables

Environment variables are external configuration values provided to an application at runtime.

They allow developers to separate:

- Application logic
- Configuration settings
- Secret credentials

Example:

```
Application Code
        |
        |
 Environment Variables
        |
        |
 API Credentials
```

This approach improves:

- Security
- Deployment flexibility
- Configuration management

---

# 8. The `.env` File

A `.env` file is a common method for storing environment variables during local development.

Example:

```env
OPENAI_API_KEY=sk-proj-your-key
```

The application loads these values when it starts.

The `.env` file should be excluded from version control using `.gitignore`.

Example:

```text
.env
```

This prevents accidental exposure of API credentials.

---

# 9. Environment Variable Rules

Environment variables follow a strict format:

```env
VARIABLE_NAME=value
```

For OpenAI:

Correct:

```env
OPENAI_API_KEY=sk-proj-example
```

Incorrect:

```env
OPENAI_API_KEY = sk-proj-example
```

Incorrect:

```env
OPENAI_API_KEY="sk-proj-example"
```

Important rules:

- Variable names are case-sensitive.
- No spaces should exist around `=`.
- Values should be copied exactly.
- API keys should not be modified.

---

# 10. Alternative AI Providers

Different providers use different environment variable names.

## OpenRouter

```env
OPENROUTER_API_KEY=your-key
```

---

## Google Gemini

```env
GOOGLE_API_KEY=your-key
GEMINI_API_KEY=your-key
```

Both variables should contain the same credential.

---

## Ollama

Local Ollama models do not require API keys because the models run locally.

No `.env` configuration is required.

# 13. Loading Environment Variables

Python applications commonly use the `python-dotenv` package to load values from `.env` files.

The first step is importing the library:

```python
from dotenv import load_dotenv
```

The environment variables are then loaded using:

```python
load_dotenv()
```

A successful load returns:

```text
True
```

This indicates that Python successfully located and processed the `.env` file.

---

# 14. Troubleshooting Environment Loading

If:

```python
load_dotenv()
```

returns:

```text
False
```

check the following:

## File Location

The `.env` file should be located in the project root.

Example:

```
project/
│
├── .env
├── 1_foundations/
├── src/
└── other files
```

---

## File Name

The file must be exactly:

```text
.env
```

Incorrect examples:

```text
.env.txt
```

```text
environment.env
```

---

## Variable Name

The variable name must match the code exactly:

```env
OPENAI_API_KEY=your-key
```

Environment variables are case-sensitive.

---

# 15. Verifying the API Key

After loading the environment variables, the API key can be accessed through Python's environment system.

Example:

```python
import os

key = os.getenv("OPENAI_API_KEY")

print(f"OpenAI API key exists: {key.startswith('sk-proj-')}")
```

Expected output:

```text
OpenAI API key exists: True
```

This confirms:

- The `.env` file was loaded.
- The environment variable exists.
- The API key follows the expected format.

# 16. Creating the OpenAI Client

The OpenAI Python SDK provides a client object used for API communication.

Create the client:

```python
from openai import OpenAI

openai = OpenAI()
```

The client automatically reads:

```env
OPENAI_API_KEY
```

from the environment.

Once initialized, Python applications can send requests to OpenAI models.

# 17. Common Setup Errors

## Import Errors

Example:

```text
ModuleNotFoundError
```

Cause:

- Incorrect Python environment
- Missing dependencies
- Wrong notebook kernel

Solution:

Verify that the notebook is running inside:

```text
.venv
```

---

## Name Errors

Example:

```text
NameError
```

Cause:

- Running notebook cells out of order

Solution:

Restart the notebook and execute cells sequentially.

---

## Authentication Errors

Possible causes:

- Incorrect API key
- Incorrect environment variable name
- Missing `.env` file
- Unsaved changes

Verify:

```env
OPENAI_API_KEY=sk-proj-your-key
```
