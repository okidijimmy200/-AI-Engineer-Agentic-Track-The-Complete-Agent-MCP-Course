# 04. Environment Setup

---

## 1. Introduction

Before building AI agents, you must configure your development environment. This process is straightforward in most cases, but occasional obstacles may arise. The tools and skills developed during setup will prove valuable throughout the course.

---

## 2. The UV Package Manager

This course uses **UV**, a modern Python package manager designed for speed and reliability. UV handles dependency resolution faster than traditional tools and reduces environment-related errors significantly.

---

## 3. API Providers and Cost Considerations

### 3.1 Available Providers

The course supports multiple language model providers:

- **OpenAI** — Recommended for consistency; total cost under $5 for the entire course
- **Anthropic Claude** — Full-featured alternative
- **Gemini** — Free tier available
- **OpenRouter** — Access to various free and low-cost models
- **DeepSeek** — Budget-friendly option
- **Ollama** — Local models requiring no API costs

### 3.2 Cost Expectations

| Approach | Total Cost | Quality Trade-off |
| :--- | :--- | :--- |
| OpenAI (recommended) | Under $5 | Best consistency |
| Free models only | $0 | Requires more iteration |
| Real-time data (optional) | Up to $200 | Maximum capability |

Detailed provider configuration instructions are available in **Guide 9** within the Guides folder.

## 5. The AI Engineering Mindset

### 5.1 Two Complementary Disciplines

AI engineering requires fluency in both software engineering and data science approaches:

| Software Engineering | Data Science |
| :--- | :--- |
| Deterministic outcomes | Statistical thinking |
| Structured architecture | Experimental design |
| Predictable systems | Iterative refinement |

### 5.2 Working with Language Models

Language models are statistical systems that may produce varying outputs given identical inputs. This variability is intentional and powerful, but requires acceptance of non-deterministic behavior. Successful practitioners:

- Design experiments to test model behavior
- Iterate based on observed results
- Remain patient when outputs differ from expectations

## 7. Setup Process Overview

All students follow the same five-step sequence:

1. **Install an IDE** — Cursor or equivalent development environment
2. **Clone the repository** — Download course materials locally
3. **Configure UV** — Set up the Python package manager
4. **Select an API provider** — Choose and configure model access
5. **Create environment file** — Set API keys and verify functionality

Operating system-specific instructions follow in subsequent lectures.
