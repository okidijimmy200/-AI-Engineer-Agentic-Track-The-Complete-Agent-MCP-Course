## II. Secure Environment and Multi-Provider Setup

Managing multiple API keys requires a secure and organized approach. The standard practice in AI engineering is the use of environment variables stored in a `.env` file.

### A. Loading Environment Variables

We use the `dotenv` library to load keys for OpenAI, Anthropic, Google, DeepSeek, and OpenRouter into the Python environment.

```python
from dotenv import load_dotenv
import os
from openai import OpenAI

# Load the API keys into environment variables
# override=True ensures that any existing environment variables are updated
load_dotenv(override=True)
```

### B. Comprehensive API Key Validation

Before initiating complex workflows, it is essential to programmatically verify that all required keys are correctly loaded. The following function provides a summary of the available keys.

```python
def check_keys():
    keys = {
        "OpenAI": os.getenv('OPENAI_API_KEY'),
        "Anthropic": os.getenv('ANTHROPIC_API_KEY'),
        "Google": os.getenv('GOOGLE_API_KEY'),
        "DeepSeek": os.getenv('DEEPSEEK_API_KEY'),
        "OpenRouter": os.getenv('OPENROUTER_API_KEY'),
        "Grok": os.getenv('GROQ_API_KEY') # Groq with a Q
    }
    
    for provider, key in keys.items():
        if key:
            # Masking keys for security while confirming existence
            print(f"{provider} API Key exists and begins {key[:8]}")
        else:
            print(f"{provider} API Key not set")

check_keys()
```

## IV. Implementation: The Multi-LLM Challenge

The core exercise for today involves asking a flagship model to generate a challenge for other, smaller models. This is a foundational step in building an automated evaluation pipeline.

### Step 1: Generating the "Nuanced Question"

Instead of a human picking the test question, we delegate this to the "strongest model on the planet" (GPT 5.5) to ensure the challenge is sufficiently complex.

**Prompt Requirements**:

- **Non-Mathematical**: To avoid simple logic puzzles and instead test "intelligent insight."

- **Succinct**: The answer must be short (e.g., no more than two sentences).

- **Thought-Provoking**: Designed to evaluate the "intelligence" of subsequent models.

```python
request = """
Please come up with a challenging, nuanced question 
with a succinct answer that I can ask a number of LLMs 
to evaluate their intelligence. 

Not a mathematical puzzle, but rather a thought-provoking 
question that requires intelligent insight. 

Include in your question that the answer must be short.
Answer only with the question, no explanation.
"""

messages = [{"role": "user", "content": request}]
```

### Step 2: Executing the Flagship Call

The request is packaged into the standard list of dictionaries and sent to the high-tier model.

```python
# Create the client instance
openai = OpenAI()

# Call the flagship model (GPT 5.5)
response = openai.chat.completions.create(
    model="gpt-5.5", 
    messages=messages
)

question = response.choices[0].message.content

# Display the question with proper formatting
from IPython.display import Markdown, display
display(Markdown(question))
```

In the lab demonstration, this resulted in the following question:

> *"What is one human virtue that can become a vice when optimized too aggressively and why? Answer in no more than two sentences."*
