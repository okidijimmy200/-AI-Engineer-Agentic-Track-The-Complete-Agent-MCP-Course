## II. Secure Environment and Key Management

Managing multiple API keys requires a secure and organized approach. The standard practice in AI engineering is the use of environment variables.

### A. The `.env` File

All sensitive keys (OpenAI, Anthropic, Google, DeepSeek, etc.) must be stored in a `.env` file to prevent accidental exposure in code repositories.

- **Format**: `PROVIDER_API_KEY=your_key_here`

- **Loading**: Use the `dotenv` library to load these variables into your Python environment.

- **Troubleshooting**:
  - **NameError**: Refer to FAQ Question 4.
  - **ImportError**: Refer to FAQ Question 5.

### B. API Key Validation

Before initiating complex workflows, it is essential to programmatically verify that all required keys are correctly loaded.

- **OpenRouter Keys**: Typically begin with the prefix `sk-or`.

- **Google Keys**: Often begin with `AI...` (though formats may vary).

- **Validation Logic**: A simple check to ensure the environment variable exists and matches the expected provider format.

## IV. Implementation: The Multi-LLM Challenge

The core exercise for today involves asking a flagship model to generate a challenge for other, smaller models.

### Step 1: Generating the "Nuanced Question"

Instead of a human picking the test question, we delegate this to the "strongest model on the planet" (GPT 5.5) to ensure the challenge is sufficiently complex.

- **Prompt Requirements**:
  - **Non-Mathematical**: To avoid simple logic puzzles and instead test "intelligent insight."
  - **Succinct**: The answer must be short (e.g., no more than two sentences).
  - **Thought-Provoking**: Designed to evaluate the "intelligence" of subsequent models.

**Example 1.1: The Request for a Question**

```python
request = """Please come up with a challenging, nuanced question 
with a succinct answer that I can ask a number of LLMs to 
evaluate their intelligence. Not a mathematical puzzle, 
but rather a thought-provoking question that requires 
intelligent insight. Answer only with the question."""
```

### Step 2: Executing the Flagship Call

The request is packaged into the standard list of dictionaries and sent to the high-tier model.

**Example 1.2: Calling GPT 5.5**

```python
response = openai.chat.completions.create(
    model="gpt-5.5", # Flagship model
    messages=[{"role": "user", "content": request}]
)
question = response.choices[0].message.content
display(Markdown(question))
```

In the lab demonstration, this resulted in the following question:

> *"What is one human virtue that can become a vice when optimized too aggressively and why? Answer in no more than two sentences."*
