# Lecture Note: 28. Visible Agent Loop (with Code Integration)

## Introduction

In this final "extra" lecture of the foundations module, we peel back the curtain on the **Agent Loop**. While the Digital Twin operated with a behind-the-scenes loop, modern agentic tools like Claude Code and Cursor CLI feel more "tangible" because they provide a visible, step-by-step manifestation of their reasoning. In this session, we will implement a **Visible Agent Loop** using a Terminal User Interface (TUI) and a dynamic checklist tool, demonstrating how transparency in reasoning leads to better outcomes and a more engaging user experience.

## I. The Psychology of the Visible Loop

What makes an agent feel "autonomous"? It is often the combination of two simple elements:

1. **Terminal UI (TUI)**: A retro-style interface that provides a sense of direct communication between the human and the machine.

1. **Checklists**: A plan-and-execute strategy where the agent explicitly lists its steps and ticks them off one by one.

By giving an LLM a tool to manage a checklist, we encourage it to plan its activities, which often results in more thoughtful reasoning and higher-quality results.

## II. Implementing the Checklist Tools

We define a simple system to track a list of strings (the tasks) and a list of booleans (the completion status).

### A. The `create_checklist` and `mark_complete` Functions

These functions provide the LLM with the ability to manage its own "to-do list" within the Python environment.

```python
checklist = []
completed = []

def create_checklist(descriptions):
    """Initializes the agent's plan."""
    global checklist, completed
    checklist = descriptions
    completed = [False] * len(descriptions)
    return get_checklist_report()

def mark_complete(index, completion_notes):
    """Marks a specific step as done with notes."""
    global completed
    if 1 <= index <= len(completed):
        completed[index-1] = True
        print(f"[bold green]COMPLETED:[/bold green] {completion_notes}")
    return get_checklist_report()
```

### B. The `get_checklist_report` Function

This function uses the `rich` library to generate a formatted, color-coded report of the agent's progress, including strikethroughs for completed tasks.

## III. Building the Terminal UI (TUI)

We use the `rich.console` library to create a formatted output that mimics the look of professional AI CLI tools.

```python
from rich.console import Console
console = Console()

def show_text(text):
    """Prints formatted markdown or rich text to the terminal."""
    console.print(text)
```

## IV. The "Visible" Agent Loop

The core logic remains the same `while` loop used in the Digital Twin, but with added transparency. Every time the LLM calls a tool to update its checklist, the UI reflects that change in real-time.

**Example 4.1: The Visible Loop Orchestration**

```python
def visible_agent_loop(messages):
    response = openai.chat.completions.create(
        model="gpt-5.5", 
        messages=messages, 
        tools=tools
    )
    
    while response.choices[0].finish_reason == "tool_calls":
        message_obj = response.choices[0].message
        messages.append(message_obj)
        
        # Handle tool calls (create_checklist or mark_complete)
        results = handle_tool_calls(message_obj.tool_calls)
        messages.extend(results)
        
        # Re-query the model to see the next step
        response = openai.chat.completions.create(
            model="gpt-5.5", 
            messages=messages, 
            tools=tools
        )
            
    show_text(response.choices[0].message.content)
```

## V. Case Study: Solving a Complex Puzzle

When tasked with a logic puzzle (e.g., the "Meeting Trains" problem), the visible loop follows a distinct pattern:

1. **Planning Phase**: The LLM calls `create_checklist` to break the problem into steps (Identify variables, Calculate relative speed, Determine meeting time).

1. **Execution Phase**: The LLM iterates through the loop, calling `mark_complete` for each step as it performs the math.

1. **Final Output**: The agent delivers the final answer only after all checklist items are crossed out.

## VI. Conclusion

The "Visible Agent Loop" is the clearest visualization of an AI agent in action. It proves that an agent is not just a black box generating text, but a system that plans, acts, and reflects. By mastering this pattern, you can build tools that are not only more powerful but also more trustworthy and transparent for the end user.
